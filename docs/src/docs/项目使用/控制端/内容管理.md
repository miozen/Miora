# 内容管理

这里主要管理文章、分类、标签、评论、留言、友链、轮播图和足迹。

## 文章管理

用于查看、搜索、编辑、删除、导入导出文章。

删除文章前确认是否还有外部链接引用，避免访问 404。

## 分类管理

分类会影响文章归档和前台菜单。

| 字段 | 填写说明 |
| --- | --- |
| 分类名称 | 前台显示名称，如“技术随笔” |
| 分类标识 | 英文或拼音，如 `tech` |
| 上级分类 | 不选就是一级分类 |
| 排序权重 | 数字越小越靠前 |
| 前台可见 | 控制前台是否展示 |
| 节点类型 | 分类、页面、导航 |
| 页面路径 | 页面类型填写，如 `/my` |
| 跳转链接 | 导航类型填写，需带 `https://` |

节点类型说明：

| 类型 | 用途 |
| --- | --- |
| 分类 | 文章归档 |
| 页面 | 跳转到前台已有页面 |
| 导航 | 跳转到外部链接 |

分类支持拖拽排序。搜索时不能拖拽，清空搜索后恢复。

## 标签管理

标签用于补充文章关键词，比如 Java、React、日常。分类管大方向，标签管细分关键词。

## 评论管理

用于查看和删除文章评论、说说评论。邮件提醒异常时，检查第三方配置里的邮件设置。

## 留言管理

管理留言墙内容。开放留言后建议定期清理广告或无效内容。

## 网站管理

用于维护友链、网站收藏、鱼塘订阅等。

| 字段 | 填写说明 |
| --- | --- |
| 网站标题 | 网站名称 |
| 网站描述 | 简短介绍 |
| 站长邮箱 | 可选 |
| 网站图标 | 图片直链 |
| 网站链接 | 需带 `http://` 或 `https://` |
| 订阅地址 | RSS 地址，没有可留空 |
| 网站类型 | 选择对应分组 |
| 顺序 | 数字越小越靠前 |

## 轮播图管理

用于配置首页轮播图。

| 字段 | 填写说明 |
| --- | --- |
| 主标题 | 轮播标题 |
| 副标题/描述 | 可留空 |
| 跳转链接 | 点击后打开的地址 |
| 封面图 | 建议 21:9 |

建议放 3～5 张，太多会影响浏览体验。

## 足迹管理

用于配置前台地图足迹。

| 字段 | 填写说明 |
| --- | --- |
| 标题 | 如“杭州 · 西湖” |
| 地址 | 用于地图解析 |
| 经纬度 | 格式：`经度,纬度` |
| 图片 | 每行一个图片链接 |
| 描述 | 足迹内容 |
| 时间 | 不能选择未来时间 |

坐标解析失败时，检查高德地图 Key。
