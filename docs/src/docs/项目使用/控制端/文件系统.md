# 文件系统

文件系统用于上传和管理图片、附件。

建议先配置 **第三方配置 > 对象存储**，再上传正式素材。

## 上传建议

| 用途 | 建议 |
| --- | --- |
| 文章封面 | 16:9 |
| 轮播图 | 21:9 |
| 头像 / 图标 | 正方形 |
| 普通图片 | 尽量压缩后上传 |

## 素材库

文章封面、轮播图、足迹、说说等位置都可以从素材库选择图片。已上传过的图片不用重复上传。

## 图片地址使用

上传后会得到图片地址，可用于文章、封面、友链头像、轮播图等。

Markdown 中这样写：

```markdown
![图片说明](https://你的图片地址.png)
```

## 常见问题

### 图片不显示

检查：

1. 图片地址能否直接打开。
2. 存储桶是否公开读。
3. 访问域名是否正确。
4. HTTPS 证书是否正常。
5. 本地存储静态目录是否映射。

### 图片加载慢

通常是图片太大或没有 CDN，建议压缩后上传。

### 删除图片

删除前确认是否被文章、轮播图、足迹等内容引用。
