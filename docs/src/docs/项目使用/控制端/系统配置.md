# 系统配置

系统配置用于修改网站基础信息、管理员账号、主题和个人资料。

## 网站配置

入口：**系统 > 系统配置 > 网站配置**。

| 字段 | 填写说明 |
| --- | --- |
| 网站名称 | 网站标题，如 `ThriveX` |
| 网站副标题 | 一句简短标语 |
| 网站链接 | 前台地址，如 `https://example.com/` |
| 网站图标 | favicon 地址，可留空 |
| 网站描述 | 简短介绍网站内容 |
| 网站关键词 | 用英文逗号分隔，如 `Java,前端,博客` |
| 底部信息 | 底部展示文案 |
| ICP 备案号 | 没有备案可留空 |
| 网站创建时间 | 用于展示站点运行时间 |

## 账户配置

用于修改管理员账号和密码。

| 字段 | 填写说明 |
| --- | --- |
| 管理员账号 | 5～16 个字符 |
| 管理员旧密码 | 当前密码 |
| 管理员新密码 | 6～16 个字符 |

修改成功后需要重新登录。

## 主题配置

用于调整前台展示风格。不确定时保持默认即可。

## 个人信息配置

常用项：

| 字段 | 建议 |
| --- | --- |
| 头像 | 使用正方形图片 |
| 昵称 | 前台展示名称 |
| 简介 | 简短自然即可 |
| 社交链接 | 能公开访问再填写 |

其他开关不确定含义时，建议先保持默认。
