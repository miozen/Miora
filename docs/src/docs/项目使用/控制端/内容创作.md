# 内容创作

控制端主要通过 **谱写** 和 **闪念** 发布内容。

| 功能 | 适合发布 |
| --- | --- |
| 谱写 | 教程、总结、长文章 |
| 闪念 | 日常、图片、短想法 |

发布前建议先建好分类，并把常用图片上传到文件系统。

## 发布文章

入口：**创作 > 谱写**。

编辑器支持 Markdown，常用写法：

```markdown
# 一级标题

## 二级标题

- 列表内容

![图片说明](图片地址)
```

点击发布后填写文章信息：

| 字段 | 填写说明 |
| --- | --- |
| 文章标题 | 文章名称，尽量简短清楚 |
| 文章摘要 | 一两句话说明文章内容 |
| 封面图 | 填图片链接，或从素材库选择，建议 16:9 |
| 归属分类 | 至少选择一个分类 |
| 关联标签 | 可选择已有标签，也可输入后回车创建 |
| 发布时间 | 默认当前时间，不能选择未来时间 |
| 可见性 | 公开、首页隐藏、全站隐藏 |
| 置顶文章 | 开启后会优先展示 |
| 访问加密 | 开启后需要填写访问密码 |

## 可见性说明

| 选项 | 效果 |
| --- | --- |
| 公开 | 正常展示 |
| 首页隐藏 | 文章可访问，但首页不展示 |
| 全站隐藏 | 前台基本不展示 |

没写完可以存为草稿，后续在 **草稿箱** 继续编辑。

## 发布闪念

入口：**创作 > 闪念**。

适合发布短内容、生活记录、图片动态。填写内容、图片、时间后发布即可。

## AI 填充

发布表单里的 **AI 填充** 可根据正文生成标题和摘要。使用前需要先配置助手模型，生成后建议手动检查一遍。
