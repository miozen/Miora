# 前端功能说明

前端是访客看到的网站页面，内容主要来自控制端。

## 首页

首页通常展示网站信息、轮播图、文章列表、分类标签和个人资料。

内容异常时检查：

| 问题 | 检查位置 |
| --- | --- |
| 网站信息不对 | 系统配置 |
| 轮播图不显示 | 轮播图管理 |
| 文章不显示 | 文章状态、分类可见性 |
| 图片打不开 | 文件系统、对象存储配置 |

## 文章页

文章页展示正文、目录、标签、评论等内容。

注意：

- **首页隐藏**：文章可访问，但首页不展示。
- **全站隐藏**：前台基本不展示。
- **访问加密**：访客需要输入密码。

## 分类和标签

分类页按分类展示文章，标签页按标签展示文章。

没内容时检查文章是否公开、是否选择了对应分类/标签、分类是否前台可见。

## 说说和留言

| 页面 | 内容来源 |
| --- | --- |
| 说说页 | 闪念 / 说说管理 |
| 留言墙 | 留言管理 |

垃圾留言较多时，可以开启人机验证。

## 友链和网站页

内容来自 **网站管理**。网站链接要能正常访问，图标必须是图片直链。

## 足迹页

内容来自 **足迹管理**。地图异常时检查高德 Key 和经纬度格式。

经纬度格式：

```text
经度,纬度
```

## RSS

RSS 地址一般是：

```text
https://你的域名/api/rss
```

没有内容时，先确认文章已公开发布。

## SEO

重点填好网站标题、描述、文章标题、文章摘要、分类和标签。不要堆关键词，内容清楚更重要。
