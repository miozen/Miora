# 后端使用说明

后端负责数据和接口，前端、控制端都需要通过后端读写数据。

## 主要作用

- 管理登录和管理员账号。
- 提供文章、分类、标签、评论等接口。
- 处理文件上传。
- 保存第三方配置。
- 发送邮件提醒。
- 提供 RSS、统计、页面配置等接口。

日常使用基本都在控制端完成，不需要频繁修改后端代码。

## 关键配置

| 配置 | 作用 | 填错影响 |
| --- | --- | --- |
| 数据库 | 保存业务数据 | 启动失败或数据异常 |
| Redis | 缓存、验证码等 | 部分功能异常 |
| 文件存储 | 保存图片附件 | 上传失败或图片打不开 |
| 邮件 SMTP | 发送提醒邮件 | 邮件发不出去 |
| 域名 / 跨域 | 允许前端访问接口 | 请求接口失败 |

## 排查顺序

接口或上传异常时，按顺序检查：

1. 后端服务是否运行。
2. API 地址是否配置正确。
3. HTTPS 证书是否正常。
4. 防火墙 / 安全组是否放行端口。
5. 对象存储或本地目录权限是否正常。

## 注意事项

- 不建议直接改数据库配置，必须改之前先备份。
- 更新后端前先备份数据库和上传文件。
- 正式站点建议先在测试环境验证，再更新生产环境。
